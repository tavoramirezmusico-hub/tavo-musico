# TAVOMUSICO - Sitio Web Personal

Sitio web oficial de **TAVOMUSICO**, multiinstrumentista y cantante costarricense.

## Características

- Diseño oscuro moderno
- Totalmente responsivo
- Menú hamburguesa con animación
- Galería con lightbox y efectos hover
- Animaciones al hacer scroll
- Enlaces a correo y WhatsApp
- SoundCloud integrado
- Estadísticas animadas
